# Apple

Clone of apple's website.

## Tech stack

- Framework: React
- Build tool: Vite
- Package Manager: PNPM
- Styling: Tailwind CSS

## Prerequisites

Ensure you have a working installation of *Node.js* and *PNPM*.

## Running the project

1. Clone the project:
```bash
git clone https://github.com/pxlblink/apple
cd apple
```

2. Install project dependencies:
```bash
pnpm install
```

3. Run a development server to view the project:
```bash
pnpm dev
```
